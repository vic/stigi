## Why AGPL

As AI writes more of the software the world runs on, the tools that verify, bound and explain that software should not belong to one closed vendor. Stigi is licensed under the GNU AGPL, so it stays free and auditable for everyone. Anyone can read the rules, audit the proofs and build on top of it. Like with the Linux kernel, companies can build on it too.

## Early adopters

Even more valuable right now: people who put Stigi to work on a real problem. A verified C library inside your Python, Rust or Go stack. A tight parser or schema engine. An agent tool runtime. A small systems utility.

Try it, push on the rough edges, and [open an issue](https://github.com/vic/stigi/issues) when a rule rejects something sensible. Real users shipping real work are what turn a good compiler idea into something people rely on every day.
