Stigi is made for agents to write and read. These tools, formats and benchmarks show where agents work today.

## Token formats and decoding

- [llguidance](https://github.com/guidance-ai/llguidance) — constrained decoding library. Grammar-constrained generation for local models.
- [Outlines](https://github.com/dottxt-ai/outlines) — constrained decoding library. Grammar-constrained generation for local models.
- [SGLang](https://github.com/sgl-project/sglang) — LLM serving engine. Structured generation at serving time.
- [SimPy](https://github.com/v587su/SimPy) — compact Python syntax study. Shows the limits of saving tokens with syntax.
- [TOON](https://github.com/toon-format/toon) — token-efficient data format. Stigi also saves tokens with compact tables.
- [TOON website](https://toonformat.dev) — home of the TOON format. The format spec and benchmarks.
- [vLLM](https://github.com/vllm-project/vllm) — LLM serving engine. Structured outputs at serving time.
- [XGrammar](https://github.com/mlc-ai/xgrammar) — constrained decoding engine. Grammar-constrained generation for local models.

## Agent tools and protocols

- [Antigravity CLI](https://antigravity.google/) — agent CLI. Talks to a Stigi image over MCP.
- [Claude Code](https://www.anthropic.com/claude-code) — agent CLI. Talks to a Stigi image over MCP.
- [Jujutsu](https://github.com/jj-vcs/jj) — version control system. Stigi works well with its change model.
- [Kiro](https://kiro.dev/) — spec-driven coding agent. Stigi also starts from specifications.
- [Model Context Protocol](https://modelcontextprotocol.io/) — tool protocol. Stigi exposes its tools through it.
- [Revia](https://github.com/regrevia/Revia) — revision-pinned semantic editing. Stigi also pins edits to revisions.
- [Smalltalk Genie](https://duckduckgo.com/?q=Smalltalk+Genie+MCP) — MCP live-graph programming tool. Stigi shares its live-graph view.

## Benchmarks

- [Aider polyglot](https://aider.chat/docs/leaderboards/) — multi-language edit benchmark. Measures how well agents edit real code.
- [DeepSWE](https://duckduckgo.com/?q=DeepSWE+benchmark) — coding agent benchmark. A shared yardstick for coding agents.
- [LibraryDesignBench](https://duckduckgo.com/?q=LibraryDesignBench+benchmark) — library design benchmark. A shared yardstick for coding agents.
- [SWE-bench](https://www.swebench.com/) — coding agent benchmark. A shared yardstick for coding agents.
- [Swe-Marathon](https://duckduckgo.com/?q=Swe-Marathon+benchmark) — long-horizon coding benchmark. A shared yardstick for coding agents.
