Stigi is built so people can understand what code does: theory sheets, decision tables, checked docs and tests that attack the checker. These papers show how people understand programs, and how tests find errors.

## Program comprehension and notation

- [Programming as Theory Building](https://scholar.google.com/scholar?q=Programming+as+Theory+Building+Naur) — Naur, 1985.
- [Why Looking Isn't Always Seeing](https://scholar.google.com/scholar?q=Why+Looking+Isnt+Always+Seeing+Petre+CACM+1995) — Petre, CACM 1995.
- [Cognitive Dimensions](https://scholar.google.com/scholar?q=Green+Petre+1996+Usability+analysis+of+visual+programming+environments+cognitive+dimensions) — Green and Petre, 1996.
- [Literate Programming for Human and Machine Agents](https://arxiv.org/abs/2608.24644) — arXiv.
