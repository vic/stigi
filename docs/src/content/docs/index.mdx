## About

AI writes code faster than any team can read it. It also cheats: it deletes failing tests, weakens checks and fills projects with glue nobody asked for.

Stigi is a systems language built for that world. Every piece of code enters a program through one door. Before anything gets in, one Datalog engine proves that memory is used safely, that indexes stay in bounds, that numbers never overflow, that the stack never runs out and that files and sockets are always closed. Code that cannot be proved stays out. There is no garbage collector, no runtime panic and no out-of-memory kill.

## What makes Stigi different

	<Feature icon="proof" title="Proved before it runs">
		Memory, bounds, arithmetic, stack depth and resource protocols are checked together, by one engine, at compile time.

	<Feature icon="shake" title="Slop never gets in">

	</Feature>

	</Feature>
</Features>

## Get involved

Stigi is built in the open, and it compiles itself. Grab the source, open the development shell and look around. The best way to help right now is to try Stigi on a real problem and tell us what a rule rejects that it should not.

:::note[Stigi is a work in progress]
Stigi is an ambitious project, and it is still growing. I build it in the open, on my own time and with my own money. If you want to see it happen sooner, [sponsoring it](https://github.com/sponsors/vic) is the most direct way to help. Trying it on a real problem and [telling us what breaks](https://github.com/vic/stigi/issues) helps just as much. Thank you :)
:::
